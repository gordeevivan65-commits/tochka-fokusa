# 🎯 Проект «Точка Фокуса»

**«Точка Фокуса»** — это единая цифровая система для педагогов, которая берет на себя повседневную рутину: отчётность, планирование, поиск материалов и рабочую коммуникацию. Всё собрано в одном пространстве, чтобы учитель мог сосредоточиться на главном — на преподавании и учениках.

---

## 🛠 Используемые технологии

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
- **Backend (раздача статики):** Python 3.11, Flask
- **Контейнеризация:** Docker
- **Библиотеки:** См. файл `requirements.txt`

---

## 📂 Структура проекта

- `index.html` — главная страница приложения (интерфейс).
- `style.css` — стили (темная пиксельная тема).
- `script.js` — вся логика работы (расписание, генератор КТП, тесты, карточки, чат).
- `app.py` — микросервер на Flask для раздачи статических файлов.
- `requirements.txt` — список зависимостей Python (только Flask).
- `Dockerfile` — инструкция для сборки Docker-образа.
- `README.md` — этот файл с документацией.

---

## ⚙️ Предварительные требования

Для запуска проекта вам потребуется:
1. **Docker Desktop** (скачать можно с [официального сайта](https://www.docker.com/products/docker-desktop/)).
2. *Или* **Python 3.10+** (если вы хотите запустить без Docker).
